A ideia principal do projeto é criar uma camada de intermédio para que possam ser feitas diversas integrações de ferramentas corporativas. Inicialmente, trabalharemos com o ClickUp usando a API deles.

A ideia é criar uma aplicação web que reúne informações sobre tarefas, datas, marcos e registro de horas para centralizar as informações com outras ferramentas (próximas etapas). A proposta é que teríamos um usuário que serviria como espécie de "bot" para pegar as informações do ClickUp tendo permissões de LEITURA apenas.

O primeiro passo, antes de gerar qualquer código, é trabalhar a arquitetura do projeto: qual framework/linguagem usar para backend e para o frontend também. Minha ideia é usar Python no Backend e Vite para o front. Podemos discutir sobre isso conforme for necessário.

A princípio, não quero montar uma rotina de testes, pois preciso avaliar o que precisa ser testado (podemos conversar sobre isso mais pra frente também, quando um MVP já existir).
